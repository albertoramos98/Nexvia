# Nexvia – Kapazi Cooperkap

Réplica fiel do site oficial [Nexvia Flooring Showcase](https://nexvia-flooring-showcase.lovable.app/) para distribuição e representação oficial Kapazi Cooperkap em Recife e região metropolitana.

## 🚀 Tecnologias

- **React 18**
- **Vite 6**
- **Tailwind CSS**
- **Lucide React**

## 📦 Funcionalidades

- **Catálogo Completo**: 30 soluções em pisos, tapetes e revestimentos em 5 categorias oficiais.
- **Assistente com IA**: Recomendações inteligentes baseadas no tipo de ambiente e fluxo de pessoas.
- **Imagens e Assets Oficiais**: Fotografias em alta resolução de todos os produtos e logotipos da marca.
- **Conversão Direta**: Botões integrados com WhatsApp e e-mail com mensagens pré-formatadas.
- **100% Responsivo**: Layout otimizado para celulares, tablets e desktops.

## 🛠️ Como Executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build

# Visualizar build localmente
npm run preview
```
